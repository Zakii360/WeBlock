# WeBlock
Opensource adblocker for YouTube and targets Google Vignette and more annoying popups that pollute the internet!

I've recently gotten into adblocking while integrating things like `ublock` and `EasyList` into a browser I'm making and thought of the idea to do something totally original that the entire world **totally** didn't think of doing! Making an Adblocker!

My main goals for this were to block Google Vignette and YouTube ads since those are the most annoying but then I realized we can also block other popups as a bonus using public filter lists and an actions workflow. Another option I proposed was using `Consent-O-Matic`'s amazing development and integrate that as a "default-off" feature in WeBlock. 
I named it WeBlock because like it's opensource and everyone who contributes is technically blocking ads..............
